Règles de confidentialité de l'application Mélodata

Dernière mise à jour : 11 novembre 2026.

Qui utilise cette application

L'application Mélodata est un outil interne utilisé uniquement par la chaîne YouTube Mélodata pour gérer sa propre chaîne. Elle n'est pas proposée au public.

Données utilisées

  • Les commentaires publics laissés sous les vidéos de la chaîne Mélodata, pour repérer les demandes de prénoms et y répondre.
  • Les statistiques YouTube Analytics de la chaîne Mélodata (vues, durée de visionnage, abonnés), pour mesurer quelles vidéos fonctionnent.

Seul le prénom demandé dans un commentaire est réutilisé, pour créer une vidéo. Aucun nom de famille ni autre information personnelle n'est utilisé.

Ce que nous ne faisons pas

Aucune donnée n'est vendue, partagée avec des tiers ou utilisée pour de la publicité. Les données restent sur l'ordinateur qui gère la chaîne.

L'utilisation des données reçues des API Google respecte le Règlement sur les données utilisateur des services d'API Google, y compris les exigences d'utilisation limitée.

Suppression

Pour qu'un commentaire ne soit plus pris en compte, il suffit de le supprimer sur YouTube. Pour toute demande, écris à l'adresse ci-dessous.
